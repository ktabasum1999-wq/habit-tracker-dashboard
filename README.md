# Interactive Habit Tracker Dashboard

## Overview

This project is a single-page Habit Tracker Dashboard built using HTML and CSS only. It provides a clean and responsive interface for visually tracking daily habits and progress.

## Features

* Daily habits section with checkbox-based state styling using the `:checked` pseudo-class
* Weekly progress grid implemented with CSS Grid
* Statistics section using Flexbox
* Styled form for adding new habits
* Responsive design using media queries
* Use of CSS variables, transitions, and keyframe animations

## Technologies Used

* HTML5
* CSS3 (Grid, Flexbox, Variables, Animations)

## Purpose

The project focuses on practicing modern CSS techniques including layout design, state-based styling, responsive UI development, and writing clean, semantic code without using JavaScript.

## Future Improvements

* Convert into a full-stack application using Flask
* Add database integration for storing habits
* Enable dynamic updates and real-time tracking

## How to Run

1. Download or clone the repository
2. Open `index.html` in any web browser
